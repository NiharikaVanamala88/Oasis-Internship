## Projects

### Task 2 – BMI Calculator

A Python command-line application that calculates Body Mass Index (BMI) using weight and height and classifies the result as Underweight, Normal, Overweight, or Obese.

**Technologies:** Python, Standard Library

### Task 3 – Random Password Generator

A Python command-line application that generates random passwords based on the selected length and character types such as uppercase letters, lowercase letters, numbers, and symbols.

**Technologies:** Python, Random, String

### Task 4 – Basic Weather App

A Python command-line application that retrieves current weather information for a city or ZIP code using the OpenWeatherMap API.

**Technologies:** Python, Requests, OpenWeatherMap API, JSON, Environment Variables
